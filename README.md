# Guild Obsidian Plugin

An Obsidian plugin for Guild integration.

## Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development build (watch mode):
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

## Antigravity Skill

This project includes the `obsidian-plugin-development` skill installed at:
- `~/.gemini/config/skills/obsidian-plugin-development/SKILL.md` (Global)
- `.agents/skills/obsidian-plugin-development/SKILL.md` (Workspace-local)
